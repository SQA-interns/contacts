# Wireframes

> For: agent (writes), human (reads) · Written in: phase 2 (`/wireframes`) · Source: `docs/02_specification.md` ("User interface"), `general/design/ui-baseline.md` · Agent: writes

Grey wireframes of every screen at the three widths (UI-22), approved by the developer before any screen is built. Files: `WF-nn_<slug>.html`, `wireframe.css`, `WF-nn_<slug>_mobile.png`, `…_tablet.png`, `…_desktop.png`.

How to read them: the UI text is the final Slovene wording (the default language, R-019-01; English comes from `en.json` with the same layout); grey bars are dynamic content (UI-28); monospace labels in dotted boxes (`State: …`, notes) are review annotations, not UI. Below the success state each page draws its other states (UI-14) as labelled sections; dialogs are drawn in place on a grey backdrop. Screen ids follow the inventory of `docs/02_specification.md` ("User interface"): WF-nn draws SC-nn.

Layout per width (UI-22..25, desktop first per `ui-design.md`): **desktop 1440** header with navigation, Group navigation as a tab bar, filter panel beside the contact list, tables with all columns; **tablet 768** the same tab bar, filters behind a "Filtri" button, one column for forms with side panels, a few low-value table columns hidden (named on the page); **mobile 375** header and Group navigation collapse into menu buttons, one column, one field per row, tables become stacked cards, the form action bar is sticky.

Navigation: WF-01 → WF-02, WF-03; sign-in → WF-04 (unverified) or WF-05; WF-05 → Group (WF-06), WF-15, WF-14 (card menu), WF-16 (user menu); Group tab bar → WF-06, WF-09, WF-10, WF-17, WF-13, WF-11, WF-12; WF-06 → WF-07, WF-08, WF-14; WF-11 → WF-12; WF-17 → WF-18; any unknown route → WF-19.
