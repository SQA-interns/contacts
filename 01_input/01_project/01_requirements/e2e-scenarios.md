# End-to-end scenarios

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

The end-to-end tests of this project: exactly one test per scenario below, run against the real local stack through the user interface. The agent writes no other end-to-end test and no scenario is merged or split. Each scenario names the stories and criteria it demonstrates; the acceptance tests carry the detailed cases, so an end-to-end test checks the journey once.

The six journeys are those of Q-54. Steps marked [ASSUMPTION] were added by `/to-spec` so that every MVP story appears in at least one scenario (DoR-R-04). Sign-up e-mails are verified through the Firebase Local Emulator Suite (Q-49).
