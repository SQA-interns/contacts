# US-011 Export the Selection to Excel

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As an Owner or Editor, I want to export the selected Contacts to an Excel file, so that I can use them in Excel and in other tools.

## Purpose

The customer's users work with Excel today and must be able to take their Contacts with them (the brief's "Integracija: Excel"). Every export of personal data must be traceable, and the file must not be a way to attack the person who opens it.

## Definitions

| Term | Meaning |
|---|---|
| Export file | An `.xlsx` file with one sheet, a header row and one row per exported Contact. |
| Attribute column | A column for one Attribute key used by at least one Contact of the Selection. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-011-01 | While the Selection is empty, the system shall show the Export button disabled. | Q-36 |
| R-011-02 | When an Owner or Editor chooses Export with a Selection of at most 10,000 Contacts, the system shall create an `.xlsx` file with one sheet, a header row and one row per selected Contact that is not in Trash. | Q-36 |
| R-011-03 | The system shall give the Export file these columns in this order: the 11 predefined fields, `Tags` (the Tag names of the Contact, comma-separated, in alphabetical order [ASSUMPTION]), then one Attribute column per key used in the Selection, ordered alphabetically [ASSUMPTION], with keys that differ only in case in one column [ASSUMPTION]. | Q-36, Q-34 |
| R-011-04 | The system shall name the Export file `<Group name>_<YYYY-MM-DD>.xlsx` with the date of the export day (project-wide facts, time zone), replacing characters that are not allowed in file names with `_` [ASSUMPTION]. | Q-36 |
| R-011-05 | If the Selection has more than 10,000 Contacts, then the system shall create no file, record no History entry and show the message that the Selection must be narrowed. | Q-36 |
| R-011-06 | If a cell value starts with `=`, `+`, `-` or `@`, then the system shall write the value as plain text, never as a formula. | Q-36, Q-48 |
| R-011-07 | When an Export file is created, the system shall record a History entry with the user, the time and the number of exported Contacts (BR-03). | Q-36, Q-37 |
| R-011-08 | If a Viewer requests an export, then the system shall create no file and record no History entry (BR-02). | Q-26 |
| R-011-09 | The system shall write the header texts and the country names in the language of the active UI language [ASSUMPTION], the cell texts in UTF-8. | Q-44 |
| R-011-10 | The system shall export the data of the Contacts as it is at the time of the export. | Q-36 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-011-01 | An Editor has nothing selected | — | The Export button is disabled | R-011-01 |
| AC-011-02 | 3 Contacts selected in Group `Acme` on 2026-11-08; one has Attribute `kompetenca=spletnoProgramiranje` | The Editor chooses Export | A file `Acme_2026-11-08.xlsx` is created with a header row, 3 data rows, the 11 predefined columns, `Tags` and a column `kompetenca` filled for the one Contact | R-011-02, R-011-03, R-011-04 |
| AC-011-03 | Contact has Tags `udelezenec2025` and `neObvescaj` | Exported | The `Tags` cell reads `neObvescaj, udelezenec2025` | R-011-03 |
| AC-011-04 | A Contact has last name `=HYPERLINK("http://x")` and notes `-1+1` | Exported | Both cells hold the text exactly as typed; neither is a formula | R-011-06 |
| AC-011-05 | The Selection has 10,001 Contacts | The Editor chooses Export | No file is created; the message asks to narrow the Selection; no History entry | R-011-05 |
| AC-011-06 | Viola is a Viewer | She calls the export directly | Refused; no file; no History entry | R-011-08 |
| AC-011-07 | An export of 3 Contacts by Boris | It completes | The Group activity list shows "Contacts exported", Boris, the time and "3" | R-011-07 |
| AC-011-08 | Journey: filter Tag `udelezenec2025`, Without-Tags `neObvescaj`, "select all N results" | The Editor exports | The file holds exactly the matching Contacts and none with `neObvescaj` | R-011-02 |
| AC-011-09 | One selected Contact is deleted after the Selection was made | The Editor exports | The file does not contain it and the History entry counts the exported rows | R-011-02, R-011-07 |
| AC-011-10 | UI language English | Export | Header cells are in English; with Slovene they are in Slovene | R-011-09 |
| AC-011-11 | A Contact was selected with company `Acme`; Boris changes it to `Beta` before the export | The Editor exports | The row shows company `Beta` | R-011-10 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-011-01 | Exactly 10,000 Contacts | File created | R-011-02 |
| EX-011-02 | 10,001 Contacts | Refused | R-011-05 |
| EX-011-03 | Cell values starting with `=`, `+`, `-`, `@` (also phone `+386 40 123 456`) | Written as text | R-011-06 |
| EX-011-04 | No Contact of the Selection has Attributes | No Attribute columns | R-011-03 |
| EX-011-05 | Keys `Kompetenca` on A and `kompetenca` on B | One column | R-011-03 |
| EX-011-06 | Group name `Acme/Beta: 2026` | File name has `_` for `/` and `:` | R-011-04 |
| EX-011-07 | Names with `Š`, `Č`, `Ž` | Shown correctly in Excel | R-011-09 |
| EX-011-08 | Contact with no Tags | Empty `Tags` cell | R-011-03 |
| EX-011-09 | Selection with a Contact of 5,000-character notes | Cell holds all 5,000 characters | R-011-02 |
| EX-011-10 | Export at 23:30 UTC on 2026-11-08 | Date in the name is `2026-11-09` (Europe/Ljubljana) | R-011-04 |

## Out of scope

Import from Excel or CSV; export to CSV; export without a Selection; several sheets; export History or Versions; formatting, colours or formulas in the file; sending the file by e-mail.
