# US-008 Search Contacts

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As a Member, I want one search box that finds Contacts by what I remember about them, so that I find a Contact without knowing which field to look in.

## Purpose

Users type what they remember — a name, a company, a Tag — and expect a result, with or without accents. A search that needs exact spelling pushes users back to Excel.

## Definitions

| Term | Meaning |
|---|---|
| Search text | The text typed in the search box; split at spaces into words. |
| Searched fields | First name, last name, e-mail, company, city, Tag names and Attribute values. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-008-01 | When a Member types search text, the system shall show only the Contacts of the Group in which every word of the search text is contained in at least one searched field, ignoring upper and lower case and accents (BR-05) [ASSUMPTION: a word matches anywhere inside a field; all words must match]. | Q-35 |
| R-008-02 | The system shall not search phone, street, postal code, country, notes or Attribute keys. | Q-35 |
| R-008-03 | When the search text changes, the system shall show page 1 of the result and the number of matching Contacts. | Q-35 |
| R-008-04 | If no Contact matches, then the system shall show "No contacts match" and a "Clear filters" button. | Q-35 |
| R-008-05 | If the search text is empty or only spaces, then the system shall treat it as no search. | Q-35 |
| R-008-06 | The system shall treat characters such as `%`, `_`, `'` and `<` in the search text as plain text. | Q-48 |
| R-008-07 | The system shall search only Contacts of the open Group that are not in Trash (BR-01, BR-04). | Q-20, Q-38 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-008-01 | A Contact with last name `Škerlj` | A Member searches `Skerlj` | The Contact is found | R-008-01 |
| AC-008-02 | Contact `Ana Novak` | A Member searches `ana nov` | The Contact is found | R-008-01 |
| AC-008-03 | Contact `Ana Novak` with Tag `udelezenec2025` | A Member searches `udelezenec` | The Contact is found | R-008-01 |
| AC-008-04 | Contact `Ana Novak` with Attribute `kompetenca=spletnoProgramiranje` | A Member searches `SPLETNO` | The Contact is found | R-008-01 |
| AC-008-05 | Contact `Ana Novak` with Attribute key `kompetenca` | A Member searches `kompetenca` and no other Contact has that text in a searched field | "No contacts match" and "Clear filters" are shown | R-008-02, R-008-04 |
| AC-008-06 | Contact `Ana Novak` with phone `040 123 456` | A Member searches `040` | No match | R-008-02 |
| AC-008-07 | A Contact `Ana Novak` is in Trash | A Member searches `Novak` | The Contact is not found | R-008-07 |
| AC-008-08 | A Contact `Ana Novak` exists in `Beta` only | A Member of `Acme` searches `Novak` | Nothing is found | R-008-07 |
| AC-008-09 | 60 Contacts; the Member is on page 3 | The Member types search text that matches 30 | Page 1 of 2 and "30 contacts" are shown | R-008-03 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-008-01 | Search text `   ` | The full list | R-008-05 |
| EX-008-02 | Search text `%` with no Contact containing `%` | "No contacts match" (not every Contact) | R-008-06 |
| EX-008-03 | Search text `'; DROP TABLE contact; --` | "No contacts match"; no error | R-008-06 |
| EX-008-04 | Search text `<script>` | "No contacts match"; shown as text | R-008-06 |
| EX-008-05 | Search text `ČEH` | Finds `Čeh` and `Ceh` | R-008-01 |
| EX-008-06 | Search text `ana novak xyz` where no field contains `xyz` | No match (all words must match) | R-008-01 |
| EX-008-07 | Search text `novak ana` | Finds `Ana Novak` (word order does not matter) | R-008-01 |

## Out of scope

Searching phone, street, postal code, notes or Attribute keys; fuzzy or phonetic matching; search across Groups; saved searches; highlighting.
