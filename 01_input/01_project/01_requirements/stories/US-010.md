# US-010 Select Contacts in the list

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As an Owner or Editor, I want to tick Contacts, a whole page or all results of a filter, so that I can export exactly those Contacts.

## Purpose

The customer wants to export "marked" Contacts. Without a Selection that survives paging and filtering, exporting a filtered result of several pages is not possible.

## Definitions

| Term | Meaning |
|---|---|
| Selection | The Contacts ticked in the contact list, or all N results of the current filter. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-010-01 | Where the Member is an Owner or Editor, the system shall show a checkbox on every row of the contact list. | Q-35, Q-26 |
| R-010-02 | While the Member is a Viewer, the system shall show no checkbox and no selection control [ASSUMPTION: Viewers cannot export, so a Selection has no use for them]. | Q-26 |
| R-010-03 | When a Member ticks a row, the system shall add that Contact to the Selection and show the number of selected Contacts. | Q-35 |
| R-010-04 | When a Member chooses "select all on this page", the system shall add all Contacts of the page to the Selection. | Q-35 |
| R-010-05 | While the Selection contains all Contacts of the page and the result has more Contacts than the page, the system shall offer "select all N results", N being the number of Contacts matching the current search and filters. | Q-35 |
| R-010-06 | When a Member chooses "select all N results", the system shall select all N Contacts, on all pages. | Q-35 |
| R-010-07 | While a Selection exists, the system shall keep it when the Member changes page or sort order. | Q-35 |
| R-010-08 | When the search text or a filter changes, the system shall clear the Selection [ASSUMPTION: the search text counts as a filter]. | Q-35 |
| R-010-09 | When a Member unticks a row or chooses "Clear selection", the system shall remove that Contact, or all Contacts, from the Selection. | Q-35 |
| R-010-10 | The system shall not change any Contact by selecting. | Q-35 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-010-01 | An Editor sees page 1 | She ticks 2 rows | "2 selected" is shown | R-010-01, R-010-03 |
| AC-010-02 | Same, 2 rows ticked on page 1 | She goes to page 2 and back to page 1 | The 2 rows are still ticked and the count is "2 selected" | R-010-07 |
| AC-010-03 | 60 Contacts, 25 per page | She chooses "select all on this page" | "25 selected" and the offer "select all 60 results" are shown | R-010-04, R-010-05 |
| AC-010-04 | Same | She chooses "select all 60 results" | "60 selected" is shown | R-010-06 |
| AC-010-05 | 60 selected | She changes a filter to 12 matches | The Selection is cleared | R-010-08 |
| AC-010-06 | 2 rows ticked | She unticks one | "1 selected" is shown | R-010-09 |
| AC-010-07 | A Viewer opens the list | — | No checkbox and no selection control is shown | R-010-02 |
| AC-010-08 | 60 selected | She chooses "Clear selection" | "0 selected"; no Contact changed | R-010-09, R-010-10 |
| AC-010-09 | 60 results selected | She changes the sort order | The Selection stays at 60 | R-010-07 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-010-01 | Exactly 25 results (one page) and the whole page selected | "select all N results" is not offered | R-010-05 |
| EX-010-02 | 26 results, whole page selected | "select all 26 results" is offered | R-010-05 |
| EX-010-03 | The page is reloaded | The Selection is empty [ASSUMPTION: the Selection lives only on the open page] | R-010-08 |
| EX-010-04 | The search text is changed back to the earlier text | The Selection stays cleared | R-010-08 |
| EX-010-05 | One selected Contact is deleted by another Member | The Selection counts it no more when exported (US-011) | R-010-06 |

## Out of scope

Other actions on a Selection (bulk Tag, bulk delete); saving a Selection; selecting across Groups.
