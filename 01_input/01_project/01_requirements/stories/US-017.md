# US-017 See the Group activity list

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As an Owner or Editor, I want one list of everything that happened in my Group, filterable by user, action and date, so that I can answer "who exported the Contacts last week?" without opening every Contact.

## Purpose

Exports and Member changes do not belong to a single Contact, so they are not in a Contact's History tab. The Group needs one place where all of them are visible.

## Definitions

| Term | Meaning |
|---|---|
| Group activity list | All History entries of a Group, newest first, 25 per page [ASSUMPTION]. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-017-01 | When an Owner or Editor opens the Group activity list, the system shall show all History entries of the Group, newest first, with time, user, action, Contact (where there is one) and details. | Q-37 |
| R-017-02 | When an Owner or Editor chooses a user, the system shall show only the entries of that user. | Q-37 |
| R-017-03 | When an Owner or Editor chooses an action, the system shall show only the entries of that action. | Q-37 |
| R-017-04 | When an Owner or Editor chooses a start date, an end date or both, the system shall show only the entries from the start of the start day to the end of the end day, both days included, in Europe/Ljubljana. | Q-37, Q-44 |
| R-017-05 | The system shall combine the chosen filters with AND. | Q-37 |
| R-017-06 | If the start date is after the end date, then the system shall show no result and a message next to the dates. | Q-37 |
| R-017-07 | If no entry matches, then the system shall show a message that no activity matches and a button to clear the filters. | Q-37 |
| R-017-08 | If a Viewer asks for the Group activity list, then the system shall refuse (BR-02). | Q-37 |
| R-017-09 | The system shall show only entries of the open Group (BR-01). | Q-20 |

| AC-017-06 | Start 2026-11-10, end 2026-11-01 | — | No result, message next to the dates | R-017-06 |
| AC-017-07 | Filters match nothing | — | "No activity matches" and a clear button | R-017-07 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-017-01 | Only a start date | All entries from that day on | R-017-04 |
| EX-017-02 | Only an end date | All entries up to the end of that day | R-017-04 |
| EX-017-03 | A user who was removed from the Group | Still selectable as a user filter [ASSUMPTION] | R-017-02 |
| EX-017-04 | 25 / 26 entries | One page / two pages | R-017-01 |
| EX-017-05 | Entry exactly at 2026-11-07 23:00 UTC (00:00 on 8 Nov local) | Not in "7 Nov"; in "8 Nov" | R-017-04 |

## Out of scope

Editing or deleting entries; exporting the list; notifications about activity; cross-Group activity.
