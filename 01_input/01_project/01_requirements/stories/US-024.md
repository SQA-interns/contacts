# US-024 Find duplicate Contacts

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As an Owner or Editor, I want a list of Contacts that probably describe the same person, so that I can clean up my Group.

## Purpose

Contacts come from Excel sheets and e-mail lists, where the same person appears several times. Duplicates lead to doubled mailings by other tools.

## Definitions

| Term | Meaning |
|---|---|
| Certain duplicate | Contacts with the same e-mail address, ignoring upper and lower case. |
| Probable duplicate | Contacts with the same first name and last name (ignoring case and accents) and the same company (ignoring case and accents) or the same phone number. |
| Same phone number | Phone numbers equal after removing spaces and `- ( ) . /` [ASSUMPTION: the interview says "the same phone number" only]. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-024-01 | When an Owner or Editor starts the duplicate search, the system shall show a list of Duplicate sets found among the Contacts of that Group that are not in Trash. | Q-41 |
| R-024-02 | The system shall put Contacts with the same e-mail address, ignoring case, into one Duplicate set marked "certain". | Q-41 |
| R-024-03 | The system shall put Contacts with the same first name and last name and the same company or the same phone number into one Duplicate set marked "probable", comparing names and companies ignoring case and accents (BR-05). | Q-41 |
| R-024-04 | The system shall never put a Contact that has no e-mail, no first name and last name, and no company into a Duplicate set. | Q-41 |
| R-024-05 | The system shall show for every Duplicate set its Contacts, its mark and the reason, for example "3 contacts share ana@acme.com". | Q-41 |
| R-024-06 | The duplicate search shall report only and change no data. | Q-41 |
| R-024-07 | The system shall never compare Contacts of different Groups. | Q-41 |
| R-024-08 | When a Contact belongs to a certain and a probable Duplicate set, the system shall show it only in the certain one [ASSUMPTION: avoids overlapping sets]. | Q-41 |
| R-024-09 | If a Viewer asks for the duplicate search, then the system shall refuse (BR-02) [ASSUMPTION]. | Q-41 |
| R-024-10 | If no Duplicate set exists, then the system shall show "No duplicates found". | Q-41 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-024-01 | Three Contacts with e-mail `ana@acme.com`, `ANA@acme.com`, `Ana@Acme.com` (stored lowercase) | The search runs | One certain set of 3 with the reason "3 contacts share ana@acme.com" | R-024-02, R-024-05 |
| AC-024-02 | `Ana Novak`, company `Acme`, no e-mail; `ana novak`, company `ACME`, e-mail `a@x.si` | The search runs | One probable set of 2 | R-024-03 |
| AC-024-03 | `Ana Novak` with phone `040 123 456` and `Ana Novak` with phone `040-123-456`, different companies | The search runs | One probable set | R-024-03 |
| AC-024-04 | `Ana Novak` and `Ana Novak`, different company and phone | The search runs | No set | R-024-03 |
| AC-024-05 | Two Contacts with only a phone number and notes | The search runs | No set | R-024-04 |
| AC-024-06 | `ana@acme.com` exists in `Acme` and in `Beta` | The search runs in `Acme` | No set | R-024-07 |
| AC-024-07 | A duplicate Contact is in Trash | The search runs | It is not in any set | R-024-01 |
| AC-024-08 | Any search | It finishes | No Contact changed | R-024-06 |
| AC-024-09 | Viola is a Viewer | She asks for the search | Refused | R-024-09 |
| AC-024-10 | No duplicates | The search runs | "No duplicates found" | R-024-10 |
| AC-024-11 | A Contact in a certain and a probable set | The search runs | It appears only in the certain set | R-024-08 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-024-01 | Names `Škerlj` and `Skerlj` | Equal | R-024-03 |
| EX-024-02 | Same name and both companies empty, phones empty | Not a probable duplicate (the match needs a company or a phone) | R-024-03 |
| EX-024-03 | One e-mail empty on both Contacts | Not a certain duplicate | R-024-02 |
| EX-024-04 | Same first name, different last name, same company | Not a duplicate | R-024-03 |
| EX-024-05 | 10,000 Contacts | The list is produced | R-024-01 |
| EX-024-06 | First name only `Ana`, same company, no last name on both | Not matched (both names are required) [ASSUMPTION] | R-024-03 |

## Out of scope

Fuzzy matching (typos, nicknames); duplicates across Groups; automatic merge; scheduled searches.
