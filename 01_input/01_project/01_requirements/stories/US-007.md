# US-007 Browse the contact list

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As a Member, I want a clear, sortable, paged list of the Contacts in my Group, so that I get a friendly overview and can open any Contact.

## Purpose

The customer's competitive advantage is ease of use. The first thing a Member sees in a Group is this list; if it is cluttered or slow, the product loses against the CRM systems it competes with.

## Definitions

| Term | Meaning |
|---|---|
| Contact list | The page of a Group that shows its Contacts, 25 per page. |
| List columns | Last name, first name, e-mail, company, city, country, Tags [ASSUMPTION: the interview says "sortable columns" but not which]. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-007-01 | When a Member opens a Group, the system shall show the Contacts of that Group that are not in Trash as a list with the list columns, 25 per page, and the total number of Contacts. | Q-17, Q-35 |
| R-007-02 | The system shall sort the list by last name ascending by default, placing Contacts without a last name after those with one and ordering equal last names by first name [ASSUMPTION]. | Q-35 |
| R-007-03 | When a Member chooses a column header, the system shall sort the list by that column, ascending, and descending on the next choice, comparing texts ignoring case and accents (BR-05) [ASSUMPTION]. | Q-35 |
| R-007-04 | When a Member chooses another page, the system shall show the Contacts of that page in the current order. | Q-35 |
| R-007-05 | When a Member chooses a row, the system shall open that Contact (US-003). | Q-17 |
| R-007-06 | While the Group has no Contact, the system shall show an empty state that explains what a Contact is; for an Owner or Editor it shall offer the action "Add contact". | Q-17 |
| R-007-07 | The system shall show no Contact of another Group and no Contact in Trash in the list (BR-01, BR-04). | Q-20, Q-38 |
| R-007-08 | If a page number beyond the last page is requested, then the system shall show an empty page with the correct total. | [ASSUMPTION] |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-007-01 | `Acme` has 60 Contacts | A Member opens `Acme` | Page 1 shows 25 Contacts sorted by last name; the total "60 contacts" is shown | R-007-01, R-007-02 |
| AC-007-02 | Same | The Member goes to page 3 | 10 Contacts are shown | R-007-04 |
| AC-007-03 | Contacts with companies `Acme`, `Beta`, `Cezar` | The Member chooses the "Company" header twice | The list is ordered by company ascending, then descending | R-007-03 |
| AC-007-04 | `Acme` has 0 Contacts | An Editor opens `Acme` | The empty state with "Add contact" is shown | R-007-06 |
| AC-007-05 | `Acme` has 0 Contacts | A Viewer opens `Acme` | The empty state without "Add contact" is shown | R-007-06 |
| AC-007-06 | One Contact of `Acme` is in Trash | A Member opens the list | The Contact is not listed and not counted | R-007-07 |
| AC-007-07 | Contact `Ana Novak` is listed | The Member chooses its row | The Contact opens | R-007-05 |
| AC-007-08 | `Beta` has Contacts | A Member of `Acme` only requests them | Not found, no data (BR-01) | R-007-07 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-007-01 | Exactly 25 Contacts | One page | R-007-01 |
| EX-007-02 | 26 Contacts | Two pages: 25 and 1 | R-007-01 |
| EX-007-03 | A Contact without last name | Listed after all Contacts with a last name | R-007-02 |
| EX-007-04 | Two Contacts with last name `Novak` and first names `Ana`, `Boris` | `Ana` before `Boris` | R-007-02 |
| EX-007-05 | Last names `Čeh`, `Cvetko`, `Cerar` | Ordered ignoring accents: `Cerar`, `Čeh`, `Cvetko` | R-007-03 |
| EX-007-06 | Page 99 of a 60-Contact list | Empty page, total 60 | R-007-08 |
| EX-007-07 | A very long company name | Truncated in the list; the full value is available | R-007-01 |

## Out of scope

Search (US-008); filters (US-009); Selection (US-010); column chooser, saved views, infinite scroll; changing the page size.
