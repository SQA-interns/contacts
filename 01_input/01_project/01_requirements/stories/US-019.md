# US-019 Switch between Slovene and English

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As a User, I want to use the product in Slovene or English and switch with one click, so that I and my colleagues can work in the language we prefer.

## Purpose

The customer is Slovene; their partners and colleagues may not be. Ease of use is the differentiator, so the language must not be a barrier. Priority and MVP are [ASSUMPTION]: the interview gives the languages but no priority.

## Definitions

| Term | Meaning |
|---|---|
| Language switch | A control in the header that shows the current language and offers the other. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-019-01 | When a visitor opens the product for the first time, the system shall show the UI in Slovene. | Q-44 |
| R-019-02 | When a User chooses the other language in the language switch, the system shall show every UI text in that language at once, without losing what the User has entered on the page. | Q-44 |
| R-019-03 | When a User opens the product again in the same browser, the system shall use the language the User chose last [ASSUMPTION: remembered in the browser]. | Q-44 |
| R-019-04 | The system shall format dates, times and numbers as the project-wide facts define for the active language. | Q-44 |
| R-019-05 | The system shall show country names in the active language. | Q-44 |
| R-019-06 | The system shall not translate text entered by users (Group names, Contact data, Tag names, Attributes). | Q-44 |
| R-019-07 | When the REST interface returns an error, the system shall show the message in the active language. | Q-44 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-019-01 | A new browser with English as browser language | The product is opened | The UI is Slovene | R-019-01 |
| AC-019-02 | UI in Slovene; a Contact form half filled | The User chooses English | All texts are English; the entered values are still there | R-019-02 |
| AC-019-03 | The User chose English and closed the browser | The product is opened again | The UI is English | R-019-03 |
| AC-019-04 | A History entry at 2026-11-08 10:00 UTC | Shown in Slovene, then in English | `8. 11. 2026 11:00`, then `2026-11-08 11:00` | R-019-04 |
| AC-019-05 | Contact country `SI` | Shown in Slovene, then in English | `Slovenija`, then `Slovenia` | R-019-05 |
| AC-019-06 | Tag `neObvescaj`, Group `Šola` | The language is switched | Both stay unchanged | R-019-06 |
| AC-019-07 | An error "contact changed by someone else" | Shown in Slovene, then in English | The message is in the active language | R-019-07 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-019-01 | Browser storage is blocked | Slovene is used at every visit; no error | R-019-01, R-019-03 |
| EX-019-02 | Language switched while a request is running | The result is shown in the new language | R-019-02 |
| EX-019-03 | Number 1234.5 shown in Slovene / English | `1234,5` / `1234.5` [ASSUMPTION for English] | R-019-04 |

## Out of scope

More than two languages; translating user data; per-User language stored on the server; right-to-left scripts.
