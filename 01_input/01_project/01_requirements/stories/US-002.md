# US-002 Create a Group and see my Groups

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As a User, I want to create a Group with a name and see all the Groups I belong to, so that I can keep the Contacts of one project or company apart from all others.

## Purpose

The customer wants Contacts of different projects and companies isolated; the Group is that unit. "Only the name is enough" (the brief), so creating a Group must take one field and one click. Without it a User has nowhere to put Contacts.

## Definitions

| Term | Meaning |
|---|---|
| Group list | The page that shows every Group of which the User is a Member, with the User's Role. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-002-01 | When a User submits a Group name that follows R-002-02 and R-002-03, the system shall create the Group with the trimmed name and make the User its Owner. | Q-07, Q-28 |
| R-002-02 | If the name is empty after trimming spaces or longer than 100 characters, then the system shall create no Group and show the rule next to the field. | Q-28 |
| R-002-03 | If the User is already the Owner of a Group that is not in Trash and whose name equals the new name ignoring upper and lower case (BR-05), then the system shall create no Group and show the message "You already have a group with this name". | Q-28 |
| R-002-04 | The system shall not limit the number of Groups a User may create. | Q-28 |
| R-002-05 | When a User opens the Group list, the system shall show every Group of which the User is a Member, with the User's Role, and no other Group. | Q-09, Q-20 |
| R-002-06 | While a User is a Member of no Group, the system shall show an empty state that explains what a Group is and offers the action "Create group". | Q-09 |
| R-002-07 | When two different Owners create Groups with the same name, the system shall accept both. | Q-28 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-002-01 | Ana is signed in and has no Group | She creates a Group named `Acme` | Group `Acme` exists, Ana is its Owner and it appears in her Group list with Role Owner | R-002-01, R-002-05 |
| AC-002-02 | Ana is signed in | She creates a Group named `  Acme  ` | The Group is named `Acme` | R-002-01 |
| AC-002-03 | Ana owns `Acme` | She creates a Group named `ACME` | No Group is created; the message "You already have a group with this name" is shown | R-002-03 |
| AC-002-04 | Ana owns `Acme`; Boris is signed in | Boris creates a Group named `Acme` | Both Groups exist and each Owner sees only their own | R-002-07, R-002-05 |
| AC-002-05 | Ana is signed in | She submits an empty name | No Group is created; the rule is shown next to the field | R-002-02 |
| AC-002-06 | Ana owns `Acme`; Boris owns `Beta` and no other Member | Boris opens his Group list | Only `Beta` is listed; `Acme` is not shown anywhere on his screens | R-002-05 |
| AC-002-07 | A User with no Group | The User opens the Group list | The empty state with the action "Create group" is shown | R-002-06 |
| AC-002-08 | Ana owns 25 Groups | She creates another | It is created; no limit message appears | R-002-04 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-002-01 | Name of 100 characters | Group created | R-002-01, R-002-02 |
| EX-002-02 | Name of 101 characters | Refused | R-002-02 |
| EX-002-03 | Name of only spaces | Refused | R-002-02 |
| EX-002-04 | Name `Šola ČŽ` | Group created with the name unchanged | R-002-01 |
| EX-002-05 | Ana owns `Acme`; she creates `acme` | Refused | R-002-03 |
| EX-002-06 | Ana owns `Acme` and the Group is in Trash | A new `Acme` is accepted [ASSUMPTION: Groups in Trash do not count] | R-002-03 |
| EX-002-07 | Ana is only an Editor in Boris's Group `Acme`; she creates her own `Acme` | Accepted (uniqueness is per Owner) | R-002-03, R-002-07 |

## Out of scope

Renaming a Group; description, logo or other properties of a Group; deleting a Group (US-020); inviting Members (US-014); a limit on Groups per User.
