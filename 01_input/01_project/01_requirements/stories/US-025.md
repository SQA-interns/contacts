# US-025 Mark a Duplicate set as "not a duplicate"

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As an Owner or Editor, I want to mark a Duplicate set as "not a duplicate", so that the same false alarm is not shown again.

## Purpose

Two people can have the same name and company. If the list keeps showing them, users stop trusting it.

## Definitions

| Term | Meaning |
|---|---|
| Dismissed set | A Duplicate set marked "not a duplicate", identified by the exact Contacts in it. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-025-01 | When an Owner or Editor marks a Duplicate set as "not a duplicate", the system shall store the set as dismissed and stop showing it. | Q-41 |
| R-025-02 | While a set is dismissed, the system shall not show a Duplicate set that consists of exactly the same Contacts. | Q-41 |
| R-025-03 | If a Duplicate set contains a Contact that was not in the dismissed set, then the system shall show it [ASSUMPTION: a bigger set is new information]. | Q-41 |
| R-025-04 | If a Viewer tries to dismiss a set, then the system shall refuse (BR-02) [ASSUMPTION]. | Q-41 |
| R-025-05 | The system shall not change any Contact when a set is dismissed. | Q-41 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-025-01 | A probable set {A, B} is shown | An Editor marks it "not a duplicate" | It disappears from the list | R-025-01 |
| AC-025-02 | Same | The search runs again | {A, B} is not shown | R-025-02 |
| AC-025-03 | {A, B} is dismissed and a new Contact C matches A and B | The search runs | {A, B, C} is shown | R-025-03 |
| AC-025-04 | Viola is a Viewer | She sends the request | Refused | R-025-04 |
| AC-025-05 | A set is dismissed | Contacts A and B are opened | Both are unchanged and no new version exists | R-025-05 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-025-01 | One Contact of the dismissed set is deleted; the rest still match as a pair of other Contacts | The remaining set is shown if it is a different set | R-025-02 |
| EX-025-02 | A dismissed set of 3, then one of them is edited so that it no longer matches | Nothing is shown | R-025-02 |
| EX-025-03 | Dismissing a set that does not exist or is in another Group | Not found | R-025-01 |
| EX-025-04 | Two Editors dismiss the same set at once | One entry is stored; both succeed | R-025-01 |

## Out of scope

Undoing "not a duplicate" [ASSUMPTION]; dismissing a single pair inside a larger set.
