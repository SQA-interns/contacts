# US-022 View and compare earlier Versions of a Contact

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

Format: `general/requirements-standard.md`.

## Story

As an Owner or Editor, I want to open an earlier Version of a Contact and compare it with the current one, so that I can see what the Contact looked like before.

## Purpose

The brief asks to version Contact changes "appropriately". The History says who changed which field; Versions show the whole Contact as it was.

## Definitions

| Term | Meaning |
|---|---|
| Version | The complete state (fields, Tags, Attributes) of a Contact after one save, numbered v1, v2, v3 …; the current state is the highest Version. |
| Versions tab | The tab of a Contact that lists its Versions. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-022-01 | When a Contact is saved (BR-07), the system shall store a Version with the new version number, the time, the user and the complete state of the Contact. | Q-40 |
| R-022-02 | When an Owner or Editor opens the Versions tab, the system shall list the Versions of the Contact, newest first, with number, time and user. | Q-40 |
| R-022-03 | When an Owner or Editor opens an earlier Version, the system shall show its fields, Tags and Attributes. | Q-40 |
| R-022-04 | When an Owner or Editor compares an earlier Version with the current one, the system shall show the fields, Tags and Attributes that differ, with both values. | Q-40 |
| R-022-05 | The system shall not change or delete a Version while the Contact exists. | Q-40 |
| R-022-06 | If a Viewer asks for a Version, then the system shall refuse (BR-02) [ASSUMPTION]. | Q-40 |
| R-022-07 | When a Contact is deleted permanently, the system shall delete its Versions (BR-04). | Q-38 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-022-01 | `Ana Novak` was saved 3 times (v1, v2, v3) | An Editor opens the Versions tab | v3, v2, v1 are listed with time and user | R-022-01, R-022-02 |
| AC-022-02 | Same, v1 has company `Acme`, v3 has `Beta` | She opens v1 | It shows company `Acme` and the Tags and Attributes of v1 | R-022-03 |
| AC-022-03 | Same | She compares v1 with the current v3 | The difference list shows company `Acme` → `Beta` and nothing else | R-022-04 |
| AC-022-04 | A Tag was added between v1 and v2 | She compares v1 with v2 | The Tag is shown as added | R-022-04 |
| AC-022-05 | Viola is a Viewer | She asks for the Versions | Refused | R-022-06 |
| AC-022-06 | A Version exists | Any request tries to change or delete it | Refused | R-022-05 |
| AC-022-07 | A Contact is deleted forever | Its Versions are looked up | They no longer exist | R-022-07 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-022-01 | A Contact with only v1 | One Version; the comparison with the current one shows no difference | R-022-04 |
| EX-022-02 | Compare the current Version with itself | "No differences" | R-022-04 |
| EX-022-03 | Version number that does not exist | Not found | R-022-03 |
| EX-022-04 | A Version of a Contact in Trash | Visible after restore only | R-022-02 |
| EX-022-05 | A save that changed nothing (US-003 R-003-11) | No new Version | R-022-01 |

## Out of scope

Restoring a Version (US-023); versions of Groups or Tags; comparing two earlier Versions with each other.
